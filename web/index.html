Your terminal, anywhere. No server in the middle.

setu connects this browser directly to a terminal shared with setu share, over an end-to-end encrypted WebRTC channel. Public nostr relays are only used to exchange encrypted connection details, and Google STUN only helps find a network path.

Start a share

# install (Go 1.27+), or grab a release binary
go install github.com/dmdhrumilmistry/setu/cmd/setu@latest

# share Claude Code (or any command), then open the printed link / scan the QR
setu share --password -- claude

Security model

  • The invite link is the key. Its secret lives after #, which browsers never send to this website.
  • Relays see only AES-GCM ciphertext, throwaway keys and a random room id.
  • Terminal traffic is DTLS encrypted peer-to-peer. Compare the verification code on both ends.
  • Optional password (PBKDF2 + HMAC challenge), view-only links, single-use links, expiry and host approval.
  • This page loads no third-party code; all libraries are vendored and pinned. You can self-host it.
