    Install

    setu is a single static binary. You need it on the machine you share from and on any machine you want to join from a terminal. Joining from a browser needs nothing installed.

    With Go

    go install github.com/dmdhrumilmistry/setu/cmd/setu@latest

    This needs Go 1.27.2 or newer. The binary lands in $(go env GOPATH)/bin (usually ~/go/bin); make sure that directory is on your PATH.

    Check the installation:

    setu version

    setu version prints the version, the commit it was built from and your platform, for example setu v0.0.0-... (1a2b3c4d5e6f 2026-10-14T12:00:00Z) linux/amd64.

    Release binaries

    Tagged releases publish binaries for Linux, macOS and Windows (amd64 and arm64) on the releases page, named setu-<version>-<os>-<arch> (.exe on Windows), together with a SHA256SUMS file.

    # Linux / macOS example
curl -LO https://github.com/dmdhrumilmistry/setu/releases/download/<version>/setu-<version>-linux-amd64
curl -LO https://github.com/dmdhrumilmistry/setu/releases/download/<version>/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
chmod +x setu-<version>-linux-amd64
sudo mv setu-<version>-linux-amd64 /usr/local/bin/setu

    On macOS, a downloaded binary may be quarantined; clear it with xattr -d com.apple.quarantine /usr/local/bin/setu.

    From source

    git clone https://github.com/dmdhrumilmistry/setu
cd setu
go build -o setu ./cmd/setu      # setu.exe on Windows

    Cross-compile with GOOS and GOARCH, for example GOOS=windows GOARCH=arm64 CGO_ENABLED=0 go build ./cmd/setu.

    Platform notes

    Windows. Hosting uses the ConPTY pseudo console, so it needs Windows 10 1809 / Server 2019 or newer. With no command, setu shares PowerShell 7 (pwsh), then Windows PowerShell, then cmd.exe. npm shims such as claude.cmd work. The shared command runs in a job object, so it cannot outlive setu.

    macOS and Linux. With no command, setu shares $SHELL (or /bin/sh).

    Networks. setu needs outbound access to the nostr relays (wss://, port 443) and to a STUN server (UDP 19302 for the default Google STUN). On networks that block peer-to-peer UDP, add a TURN server; see Strict networks.
