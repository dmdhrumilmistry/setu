# Code map

Generated by `go run ./tools/codemap` from the source; do not edit by hand. CI fails when it is out of date.

Start here to find where something lives, then open only the files you need (grep for a name to get its line). Methods are `Type.Method`; functions and methods are listed whether exported or not, types, constants and variables when exported. It holds no line numbers, so it changes only when declarations are added, removed or renamed. AGENTS.md has the architecture and conventions; docs/DESIGN.md the wire protocol.
