    Your terminal, anywhere

    setu shares a terminal on your machine with a browser or another terminal, peer-to-peer and end-to-end encrypted, with no server of your own. Built for driving Claude Code and other AI agents from your phone.

    Quick start Install View on GitHub 
    go install github.com/dmdhrumilmistry/setu/cmd/setu@latest
setu share --password -- claude

    setu prints a link and a QR code. Open it on your phone (or any browser), enter the password, check that the verification code matches, and you are in the same terminal session as your computer.

    setu means "bridge" in Sanskrit.

    What you can do

    Share a terminal

    Any command or your shell, with passwords, view-only links, single-use links, expiry and approval prompts.

    Remote desktop

    Share the whole screen, mouse, keyboard and clipboard of a Windows, Mac or Linux computer with any browser.

    Join from anywhere

    A mobile-friendly web client with a key bar and a compose box, or setu join from another terminal.

    Drive Claude Code

    Start an agent on your workstation and steer it from your phone, safely.

    Always-on service

    Persistent links that survive reboots, a personal key per person, autostart on Linux, macOS and Windows.

    Audit logging

    Who ran which command, when, from where and on what device, exported over OpenTelemetry.

    Managed devices

    Org policy through Intune, Jamf, Kandji, VaanarSena or Group Policy, enforced on every device.

    How it works

     setu share --(encrypted hello / offer / answer over nostr relays)-- browser / setu join
      |                                                                   |
      +------------- WebRTC data channel (DTLS, peer-to-peer) -------------+
    1. setu share starts your command in a pseudo terminal and creates a random 256-bit secret. The secret lives only in the link's #fragment, which browsers never send to any server.
    2. The joiner and the host exchange a few small, encrypted messages through public nostr relays to set up a WebRTC connection. Relays only ever see ciphertext. With --manual you copy and paste these messages instead and no relay is involved.
    3. The peers connect directly. Terminal bytes travel only over that DTLS encrypted channel. Both sides show a 6-digit verification code; if they match, nobody is in the middle.

    The full protocol is in Design and protocol.

    Platforms

    Share (host) Join
    Linux yes terminal or browser
    macOS yes terminal or browser
    Windows 10 1809+ / Server 2019+ yes (ConPTY; default shell PowerShell) terminal or browser
    Phones and tablets no browser

    Remote desktop hosting (setu desktop) works on Windows, macOS 12+ and Linux or BSD with an X11 session.
